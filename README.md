# أداة آيات المصحف بالرسم العثماني (MCP)

أداة تُربط بـ ChatGPT أو Claude أو أي برنامج يدعم MCP، وتجلب الآية **صورةً شفافة** مرسومة بخط حفص العثماني الرسمي لمجمع الملك فهد لطباعة المصحف الشريف.
الذكاء الاصطناعي لا يكتب الآية ولا يرسم حروفها؛ هو يصمم الخلفية فقط، والآية تأتي جاهزة من الأداة.

## المصدر
- النص: بيانات مجمع الملك فهد (KFGQPC Hafs Uthmanic Data v18)، رواية حفص عن عاصم، 6236 آية.
- الخط: خط حفص العثماني الرسمي `hafs.18.ttf`.
- **حماية من التعديل:** عند كل تشغيل يتحقق الخادم من بصمة ملف النص وملف الخط (SHA-256). إن تغيّر حرف واحد يرفض العمل. البصمات في `CHECKSUMS.sha256`.
- النص لا يمر بأي معالجة. الشيء الوحيد الاختياري هو إخفاء رقم الآية من آخرها.
- طوبق النص مع النسخة الذكية الرسمية من المجمع (Hafs Smart v8) فتطابقت الآيات كلها.

## الأدوات
| الأداة | عملها |
|---|---|
| `get_ayah_image` | صورة PNG للآية أو المقطع (لون الخط، الخلفية أو الشفافية، الحجم، المحاذاة، إظهار أرقام الآيات) |
| `get_ayah_text` | نص الآية بالرسم العثماني مع الصفحة والجزء |
| `search_quran` | البحث عن آية بكلمات منها |
| `list_surahs` | قائمة السور |

وتوجد روابط مباشرة تعمل بلا ذكاء اصطناعي:
- `/ayah.png?sura=2&from=255` — صورة آية الكرسي.
- `/ayah.png?sura=1&from=1&to=7&color=%23a07a2c&bg=%23fbf6ea` — الفاتحة بلون ذهبي على خلفية كريمية.
- `/font/hafs.18.ttf` — الخط الرسمي.

## النشر على Render (مجاني)
1. ارفع هذا المجلد إلى مستودع على GitHub.
2. في render.com اختر **New → Blueprint** واربطه بالمستودع (يقرأ `render.yaml` تلقائيًا).
3. بعد أول نشر انسخ رابط الخدمة (مثل `https://mushaf-uthmani.onrender.com`) وضعه في متغير `PUBLIC_URL`، ثم أعد النشر.
4. رابط الأداة هو: `https://<رابطك>/mcp`

يعمل أيضًا على أي خدمة تشغّل Docker (Railway وFly.io وGoogle Cloud Run وغيرها).

## الربط
- **ChatGPT:** الإعدادات ← التطبيقات والموصلات (Apps & Connectors) ← الإعدادات المتقدمة ← فعّل وضع المطوّر ← أنشئ موصلًا وضع رابط `/mcp`.
- **Claude:** الإعدادات ← Connectors ← Add custom connector ← ضع رابط `/mcp`.

## طريقة الطلب المقترحة
> صمّم بطاقة بخلفية زخرفية خضراء، واجلب آية «وَقُل رَّبِّ زِدۡنِي عِلۡمٗا» من أداة المصحف وضعها في المنتصف كما هي.

النموذج يبحث بالأداة، ويجلب صورة الآية، ثم يضعها فوق التصميم.
تنبيه: إن طلبت من مولّد الصور أن «يكتب» الآية داخل الصورة فقد يشوّهها. الصحيح أن تُركّب صورة الآية فوق التصميم. التعليمات المدمجة في الأداة توجّه النموذج لذلك.

## التشغيل المحلي
```bash
pip install -r requirements.txt   # يتطلب libraqm في النظام
python server.py                  # http://localhost:8000/mcp
```

## الترخيص
النص والخط ملك مجمع الملك فهد لطباعة المصحف الشريف، ويُستعملان وفق شروط المجمع. يُمنع تعديل الملفين.
